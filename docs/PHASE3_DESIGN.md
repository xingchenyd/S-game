# 第三阶段实施设计

## 上海篇章

上海首发篇由十个连续节点组成：虹桥撤展异常、可移动撤展通道、陆家嘴电子风险、苏州河源头控制、杨浦潮纸档案、长宁衣物维修、临港逆向物流、城市污染源汇合、世博压力演练、世博公众日终局。节点使用同一组常驻角色，并把上一节点的完成状态写入本机用户名存档。

每个主线节点包含任务目标、三段现场对话、角色名单、解锁前置和永久奖励。进入关卡后先在可移动房间寻找风险证据、去向标签和价值部件，再进入战斗、三套系统判断、局内构筑与 Boss。自由行动仍保留，便于活动现场直接选关。

## 三档难度

简单、普通、困难分别面向活动首玩、完整体验和熟练玩家。难度同时调整敌人生命、伤害、生成压力、污染增长、预警窗口、瞄准辅助和奖励倍率；简单不是删除内容，困难也不是只堆血量。

## 装备预算

普通、精良、稀有、原型的战力预算分别为 10、20、32、46。同稀有度预算相同，但属性分配与机制专长不同。装备实时影响最大生命、净化强度、攻速、移速、技能循环、弱点率、价值保留、污染防护与吸附范围。工坊提供整套评分和逐项增减对比。

## 永久能力

行动、系统、共情各三层，共九个节点。技能点只能由主线关键节点获得。六个以上节点会改变路线信息、隐藏节点、人物证词、连续判断、濒危护盾或原型档案，不把成长压缩成攻击加成。

## 现实兑换边界

第三阶段继续只保留数字稳定原型和纪念章/模型预览，不接入二维码、订单、物流、真实库存或 3D 打印后台。
