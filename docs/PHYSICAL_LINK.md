# 数字原型与现实奖励闭环

当前实现只做本机凭证预览，不连接真实订单、快递或3D打印。正式落地建议按四层推进。

## 1. 原型来源

- 每个Boss由“污染外壳＋稳定原型”组成。
- 玩家完成战斗和处理决策后才获得原型编号，不能只靠刷怪掉落。
- 原型记录关卡、材料主题和行动完成状态，不记录不必要的个人信息。

## 2. 奖励设计

- 1碎片：主题纪念章或再生材料挂牌。
- 2碎片：修补、分类、再设计线下工坊体验券。
- 3碎片：Boss破壳桌面模型，外壳可打开，内部原型可拆出。
- 回环行动员终局原型：仅在完成四类主题行动后开放，避免单关刷取。

所有奖励应自愿、按需兑换。默认不向每位通关者寄送实物，减少闲置、包装和运输。

## 3. 展会核销

```text
本机生成一次性凭证
  → 工作人员设备扫码
  → 校验活动批次、原型和是否已核销
  → 玩家选择现场领取 / 后续制作 / 放弃实物
  → 记录匿名核销状态
```

真正的二维码必须由活动后台签名生成；当前CSS二维码只是视觉占位，不可用于生产核销。

## 4. 3D打印与制作原则

- 优先模块化小尺寸模型和按需制作，避免为展示而大量预印。
- 在实物卡上标注材料来源、制作地点、预计质量、可维修/回收方法。
- 若使用再生耗材，需要验证机械性能、一致性和来源；“再生”不代表自动低环境负担。
- 打印区需要通风、设备维护和人员暴露控制；现场试玩区与制作区分离。
- 邮寄方案先确认库存、包装、地址保存期限、未成年人信息授权和退换规则。
