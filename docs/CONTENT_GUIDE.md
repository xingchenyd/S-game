# 教育内容与剧情写作规范

## 行为目标

每条内容只解决一个可观察行为，不只输出口号。标准结构是：

1. 场景：说明物品现在在哪里、状态如何。
2. 风险：解释错误动作会把什么价值或安全条件破坏掉。
3. 选择：给玩家 2–3 个现实可执行选项。
4. 反馈：先回应这次选择，再解释原因；错误选项不羞辱玩家。
5. 证据：把结论写进材料护照、行动笔记或本局指标。

## 两分钟故事模板

- 6–8 个对话节拍，约 550–850 个汉字。
- 至少两个玩家选择点；选择必须触发具体回应，不能只改变一句“答对了”。
- 废物用第一人称描述经历，但不把危险处理拟人化成鼓励冒险。
- 结尾给出可记住的一句话和一个现实动作。
- 规则易变化的内容写“以现场标识和上海当前指引为准”，避免硬编码可能过期的设施信息。

## 收藏品材料护照

每件藏品必须包含：污染前状态、正确行动、新去向、来源关卡、第一人称摘要。未获得藏品只显示轮廓和来源提示，不因当前主题自动全解锁。

## 禁止项

- 不把“击杀垃圾”作为叙事用语。
- 不把回收描述为无限消费的免责机制。
- 不鼓励普通玩家处理鼓包电池、未知化学品或危险拆解。
- 不用单一题库反复刷积分；同一行动中的决策只结算一次。
- 不用儿童化语气代替准确解释，目标用户为 10–18 岁及成人。
