# BGM 与剧情配音交付说明

## 当前已实现

游戏内置 11 套原创程序化 Web Audio 主题：开始页、基地、城市行动、展馆、剧场、训练场、装备、兑换、档案、Boss、结算。它们使用不同速度、音阶、低音和波形实时生成，不依赖外部版权音频。浏览器的自动播放规则要求用户首次点击后才开始发声。

剧情提供本机浏览器中文 TTS 预览：可逐句播放/停止，可在档案页开启自动预览并单独调节音量。不同系统的中文音色由设备决定，因此这不是正式商业配音。

## 正式配音清单

- 40 篇 × 8 节拍 = 320 个基础段落；其中玩家选择后的回应应按选项分别录制。
- 建议角色：旁白、回环行动员、电子物、塑料物、纸材物、织物物、居民/工作人员。不要用夸张低龄腔。
- 文件命名：`story_{两位篇号}_beat_{两位节拍号}_{speaker}.ogg`；选择回应用 `_choice_a/_choice_b`。
- 格式：48 kHz、24 bit 母带；网页交付 OGG + AAC，峰值不超过 -1 dBTP，整体响度约 -16 LUFS。
- 录制前从 `src/data/stories.ts` 导出锁定版台词；录制后建立台词 ID、文件、时长、审校状态表。

## 正式音乐制作建议

程序化版本可直接用于原型和无版权风险的展会试玩。若制作录音级音乐，建议以当前 11 个主题名为 cue sheet，保持可循环、2–3分钟无明显跳点，并为战斗/Boss提供同调性分层轨道，避免切换时重新起曲。必须保存作曲委托、音源许可和演奏授权证明。

## 尚需外部人员完成

真人配音、录音棚混音、商业级音乐母带和最终版权文件无法仅靠当前代码仓库产生。外部音频到位后，将文件放入 `public/audio/voice/` 与 `public/audio/music/`，按上面的 ID 建清单，再把 `speakChinese` 与程序化 `startMusic` 替换为优先播放文件、缺失时回退预览的策略。
