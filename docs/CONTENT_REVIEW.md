# 40 篇剧情资料与审校清单

## 内容规格

- 总数：40 篇，电子物、塑料、纸材、织物各 10 篇。
- 单篇：8 个剧情节拍、2 个玩家选择节点、约 1,010–1,069 个中文字符，界面标注约 2–3 分钟。
- 场景：上海公共空间为首版背景；黑独山仅作为资料站故事和未来关卡占位。故事事件与人物为教育性虚构。
- 教育结构：现场观察 → 物品/角色陈述 → 风险或价值边界 → 玩家选择 → 后果解释 → 第二次迁移判断 → 可执行结论。
- 可访问性：全部关键信息均为文字；语音只是可关闭的预览，不作为唯一信息通道。

## 已接入来源

1. 上海市生活垃圾分类投放指南（2024版）：上海市绿化和市容管理局。
2. 上海市生活垃圾管理条例：上海市人民代表大会常务委员会公开文本。
3. 废弃电器电子产品回收处理管理条例：生态环境部公开法规。
4. 废锂离子动力蓄电池处理污染控制技术规范：生态环境部标准信息。

每篇故事在数据中保存 `sourceIds`、`learningGoals`、`reviewStatus` 与字符数。当前统一标记“资料初审”，表示已按公开资料校对基本表述，但正式进校园、政府场馆或品牌公益活动前，仍应由上海垃圾分类/安全处置专业人员进行第二轮逐篇审校。

## 正式上线前人工复核步骤

1. 由本地主管或合作机构确认活动场地实际接收品类、容器标识和收运渠道。
2. 对电池、灯管、未知化学品等高风险台词进行安全审查，禁止把游戏动作当成现实操作教程。
3. 对捐赠、二手流转和数据清除内容核对合作机构真实能力，删除无法兑现的承诺。
4. 逐篇记录审校人、版本、日期和修改理由，再把 `reviewStatus` 改为“已复核”。
5. 每次规则或合作方变化时，更新资料来源日期并抽查关联故事。
