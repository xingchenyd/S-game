# S-game 成品设计说明

## 1. 产品定位

S-game 的差异点不是给普通射击游戏贴上垃圾分类题，而是让教育行为直接改变战斗资源和结局：玩家先击破污染外壳，再判断安全、清洁、分材、修补、捐赠或合规回收的顺序。正确决策降低污染率、提高价值保留并改变构筑；Boss掉落的是被保护下来的稳定原型。

四个长期指标：

1. 分类准确率：是否识别了适合本地处理路径的物品。
2. 污染控制：是否避免一件不合格物污染整批材料。
3. 价值保留：是否优先选择继续使用、维修和高质量流转。
4. 真实行动：是否把数字原型转成按需、透明、可回收的线下行动证据。

## 2. 游戏结构

```text
循环基地
  ├─ 城市行动：战斗 → 决策 → 构筑 → Boss → 原型
  ├─ 价值展馆：藏品 → 材料护照 → 来源故事
  ├─ 循环剧场：场景语料 → 玩家选择 → 行动笔记
  ├─ 装备工坊：库存 → 插槽 → 本局属性
  ├─ 现实兑换：原型碎片 → 本机凭证 → 未来线下核销
  └─ 个人档案：本机统计、设置、存档导出
```

## 3. 上海首版关卡

| 场景 | 核心技能 | Boss污染外壳 | 稳定原型 |
| --- | --- | --- | --- |
| 陆家嘴电子环线 | 断电、隔离电池、数据安全、正规渠道 | 失控锂芯兽 | 稳定锂芯原型 |
| 苏州河塑潮 | 倒空、适度清洁、分材、源头减量 | 微塑潮汐兽 | 澄净树脂原型 |

## 4. 战斗扩展接口

当前战斗已经包含移动、自动攻击、冲刺、范围脉冲、追击型和远程型敌人、Boss血量与生成逻辑。继续扩展时保持以下边界：

- 新技能必须绑定一个真实处理动作，例如隔离屏障、洁净压缩、材质扫描、优先修复。
- 新敌人由“行为角色”定义，而不是只换皮：追击者、远程泄漏者、污染源、护盾载体、召唤体。
- 新Boss包含外壳阶段、风险控制阶段和稳定原型阶段，不使用死亡尸体作为奖励。
- 场景碰撞只围绕脚底锚点；渲染层、受击层和物理层分离，避免穿模与闪烁。

## 5. 视觉系统

- 主题：精致像素绘本 × 回收工业基地。
- 正文使用系统中文字体；像素/等宽只用于编号、徽章和英文眉题。
- 8px间距网格，3px硬边框，3–8px阶梯阴影，有限的青/黄/粉/紫强调色。
- 不在同一场景拼贴不同透视、光源和像素密度的图片。
- 装备只有在具备统一角色比例、方向帧和锚点文件后才能作为人物穿戴层。

## 6. 后续内容优先级

1. 为四类主题补齐专属Boss多阶段动画和攻击预警。
2. 把路线从线性五节点扩为可视化分支：战斗、处理、故事、修复台、风险事件、Boss。
3. 增加上海区级场景资料包和场馆可配置规则文件。
4. 为蓝猫增加关键节点配音；所有信息仍保留文字，音频不作为唯一通道。
5. 在真实合作机构确定后接入签名核销，而不是提前承诺物流与打印。
