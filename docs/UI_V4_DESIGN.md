# S-game UI V4 设计与实现说明

## 目标

UI V4 解决旧界面的三个核心问题：字体像网页后台、符号图标缺乏游戏质感、进度与状态信息层级过弱。

## 字体系统

- 中文正文采用系统本地优先的粗体黑体栈，避免展会离线环境依赖在线字体。
- 普通正文默认 700 字重，按钮、标签、数值采用 900 字重。
- 小标签不再低于 11–13px；战斗核心数值使用 13–18px，并配合色彩和图标重复编码。
- 标题减少过度字距，采用更紧凑的游戏标题比例与暗色投影。

## 生成资产结构

- 32 枚语义徽章覆盖全局导航、基地设施、玩法、能力、战斗状态和主动技能。
- 9 个空白机械框体使用 CSS `border-image` 九宫格拉伸，文字和数据仍由 DOM 实时渲染。
- 所有实际切片压缩为透明 WebP；三张高清 PNG 母图保留以便重裁。

## 战斗 HUD

- 顶部高度增至 106px，区域顺序为：退出、地点/关卡名、行动进度、生命/护盾、污染、价值。
- 行动进度同时展示动态色条、百分比与节点数，避免只有一条细线。
- 生命、护盾、污染、价值分别使用独立生成徽章和数值层级。
- Q/E/空格/R 技能栏加入独立图标、按键、技能名、冷却状态和进度条。
- Boss 血条、目标提示、雷达和移动端触控技能均使用同一框体语言。

## 全局覆盖

- 登录：用户名、开始游戏、轮播箭头与登录卡框体。
- 基地：设施徽章、任务徽章、提示框、方向控制、音量和全屏。
- 行动：路线、难度、状态、玩法判断、技能与奖励。
- 训练：11 种玩法由独立徽章替换 Unicode 符号。
- 能力、装备、档案、兑换：主要语义图标替换为生成资产。

## 响应式规则

- 1000px 以下战斗 HUD 改为两行布局。
- 680px 以下保留真实中文并缩短辅助说明，不将重要数值缩成不可读小字。
- 手机基地提示框移到方向键与交互键上方，390×844 测试横向溢出为 0。
