旧项目的猫形引导角色资产已从新仓库工作版本移除，以免继续形成第三方角色联想；原文件仍可从 Git 历史和旧项目恢复。其余旧装备和主题怪物图继续作为“遗产资产”保留，后续应按统一比例、方向帧、光源和脚底锚点逐批替换。

## 第三阶段：精细 2D 污染外壳

本阶段新增四张透明底、三分之四俯视角的原创手绘角色。它们不是“垃圾拟人”，而是包裹稳定材料原型的污染外壳。Phaser 战斗会优先把它们用于 Boss、精英与部分主怪，并使用程序化呼吸、蓄力、受击闪白、阶段变色与净化破散动画。

| 文件 | 类型 | 核心视觉语义 |
| --- | --- | --- |
| `public/art/enemies-v2/electronic-shell.png` | 电子 | 鼓包电池、绝缘线、板卡外壳；青色稳定核 |
| `public/art/enemies-v2/plastic-shell.png` | 塑料 | 瓶体、薄膜、混合树脂；水色稳定核 |
| `public/art/enemies-v2/paper-shell.png` | 纸 | 受潮纸板、胶带、干燥纤维；琥珀稳定核 |
| `public/art/enemies-v2/textile-shell.png` | 织物 | 成衣、缝补线、混纺带；品红稳定核 |

生成规范：单个完整角色、透明 Alpha、无文字与水印、同一战斗视角、缩小到约 96 像素仍保持轮廓可读。生成原件保存在 Codex 的 `generated_images` 目录，项目内为独立副本。
