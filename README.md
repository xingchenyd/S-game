# S-game · 废料环线

一款面向公益活动、展会现场和个人设备的中文环境教育动作肉鸽。玩家不是“消灭垃圾”，而是击破让废弃物失控的污染外壳，完成正确处理决策，保留材料与物品价值，并收集可连接现实纪念物的稳定原型。

## 已实现

- 三张原创主视觉每 3 秒轮播；用户名即本机存档标签，无密码、无服务器账号。
- 上海首版 10 条可玩城市行动与 1 条黑独山资料占位；每条路线包含五个节点、三种绑定玩法和独有 Boss 原型。
- 11 套可独立训练的玩法系统：分支远征、污染控制、精细分拣、维修解谜、材料护送、风险隔离、设施防卫、环境机关、居民委托、护照探索、城市终局。每套均有三阶段实玩、双指标取舍、失败反馈、变体与精通目标。
- Phaser 动作战斗：键鼠/触控移动、自动攻击、蓄力工具、定向脉冲、冲刺、连击终结技、场景障碍、六类敌人行为、精英与多阶段 Boss、预警/粒子/震屏反馈。
- 完整行动闭环：委托简报 → 净化战斗 → 三套路线玩法连续判断 → 三选一构筑 → Boss污染外壳 → 稳定原型。
- 顶部本局进度条，不用倒计时强迫剧情和探索速度。
- Colorbook 思路的双区价值展馆：活页卡册、锁定雾、类别进度、常驻展示台、材料护照。
- 40 个约 2–3 分钟的中文互动故事（四类各10篇）；每篇至少8段、两次玩家选择、学习目标、来源编号和资料初审状态。
- 旧项目装备资产保留为库存，重做插槽、购买、装配和属性表达；禁止无锚点贴图覆盖人物。
- 原型碎片、纪念章/模型/工坊券本机演示凭证；不接物流和真实打印。
- 11 首按页面/战斗状态切换的原创程序化配乐、浏览器中文剧情语音预览；个人本机统计、JSON存档导入/导出、分项音量、全屏、屏幕震动、减少动态、高对比度、5分钟无人操作展会重置。
- 手机响应式布局、触控操作、安全区适配、PWA manifest 与首次访问后的运行时缓存。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 操作

- 移动：`WASD` / 方向键 / 手机左侧方向区
- 冲刺：`Space` / 手机“冲刺”
- 蓄力工具：按住 `E` / 手机“蓄力”，松开后释放方向锥形打击
- 绝缘脉冲：`Q` / 手机“脉冲”
- 满能量终结技：`R` / 手机“终结”
- 普通攻击：自动锁定最近污染体，强调移动、走位和技能节奏

## 内容与合规边界

- 首版表述以上海公共场景为背景，但实际投放仍提示玩家以现场标识和上海当前指引为准。
- 鼓包、破损或状态不明电池的剧情不鼓励普通人自行拆解、穿刺、冲洗或搬运。
- 所有用户数据只存在浏览器 `localStorage`；项目没有遥测、后台账号、订单或真实核销。
- 黑独山等脆弱地貌场景必须经过在地规则和资料核验后才能从“筹备中”切换为可玩。
