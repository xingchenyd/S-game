# UI V4 生成资产

本目录保存 S-game 的统一游戏界面资产。全部资产由 Codex 内置图像生成模式生成，再切片为透明 WebP 供网页游戏使用。

## 资产组

- `nav/`：基地、行动、训练、展馆、剧场、能力、档案、装备、兑换、设置等 16 枚功能徽章。
- `combat/`：生命、护盾、污染、材料价值、四项主动技能、增益、掉落、Boss 与雷达等 16 枚战斗徽章。
- `chrome/`：主 HUD、普通进度条、Boss 血条、三类按钮、内容面板、提示框和技能框共 9 个可伸缩框体。
- `*-atlas.png`：三套未切片高清母图，用于以后重新裁切和派生。

## 视觉规范

- 深色回收工业设施结构、再生金属划痕与粗厚倒角。
- 青色能量作为系统色；黄、绿、粉、紫分别承担价值、恢复、织物与技能提示。
- 中文不烘焙进图片，保持动态数据、移动端清晰度和无障碍阅读。
- 禁止 Emoji、网络线性图标、照片式物体与带文字图标。

## 生成提示摘要

1. 4×4 导航徽章图集：16 个基地与系统功能图标，透明背景，32–64px 仍须可辨识。
2. 4×4 战斗徽章图集：生命、护盾、污染、材料、技能、增益、掉落、Boss、雷达，透明背景，以轮廓而非仅颜色区分。
3. 3×3 UI 框体图集：空白 HUD、进度条、Boss 条、按钮、内容卡和技能框，正视、可拉伸、无文字。
